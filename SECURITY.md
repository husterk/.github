# Security policy

This policy covers every repository owned by
[husterk](https://github.com/husterk) that does not publish its own.

## Reporting a vulnerability

Report it privately. Please do not open a public issue.

- **In a public repository**, open the repository's **Security** tab and choose
  **Report a vulnerability**. The report stays private until a fix is ready.
- **Anywhere else**, or if that button is missing, email husterk@gmail.com.

Include the repository, what you found, and how to reproduce it. You should
get a reply within a few days.

## Supported versions

These are personal projects with no release branches. Fixes land on each
repository's default branch.
