# Contributing

The repositories owned by [husterk](https://github.com/husterk) are personal
projects. Issues and questions are welcome. A pull request may not be merged,
because each project is tuned to one person's use, but a pull request that
shows a bug is still a useful report.

## How changes are made

- **An issue comes first.** Every change starts from an issue with checkable
  acceptance criteria. Use the issue forms.
- **One pull request per issue.** Put `Closes #<number>` in the pull request
  body. A required check fails a pull request without it.
- **Commits** follow [Conventional Commits](https://www.conventionalcommits.org/)
  and carry a body that explains why. Commits on the default branch must be
  signed.
- **CI must pass.** Each repository's `CLAUDE.md` or README lists the local
  command for every required check.

Report security issues privately, as described in [SECURITY.md](SECURITY.md).
